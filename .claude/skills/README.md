# Project skills

Copied into the repo so they load for anyone who opens this folder in Claude Code.
Re-copy from upstream to update.

| Skill | Use it for | Source |
| --- | --- | --- |
| `animate` | Building a new animation the right way (purpose, curve, duration, interruption, exit) | [emilkowalski/skills](https://github.com/emilkowalski/skills) @ 2d22863, MIT |
| `review-animations` | Strict critique of motion code (run it explicitly: `/review-animations`) | same |
| `improve-animations` | Whole-site motion audit + prioritized plan | same |
| `find-animation-opportunities` | Where motion would help, and where it wouldn't | same |
| `animation-performance` | Janky or dropped-frame animations | same |
| `emil-design-eng` | UI polish and the invisible details | same |
| `break-ui` | Stress-test a component with worst-case content | same |
| `web-design-guidelines` | Pre-ship check against Vercel's Web Interface Guidelines | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) @ 063bee9, MIT |

Plugins (Impeccable, Superpowers, Playwright, etc.) are installed per machine by
`scripts/setup-claude-tools.sh`.
